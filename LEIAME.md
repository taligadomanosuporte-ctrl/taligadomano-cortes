# Site público (GitHub Pages)

Páginas de termos e privacidade exigidas pelo TikTok (e Google). Ao contrário do Google Sites, o GitHub Pages
permite publicar o arquivo de verificação de URL do TikTok.

1. Crie um repositório PÚBLICO no GitHub chamado `taligadomano-cortes`.
2. Envie o CONTEÚDO desta pasta (index.html, estilo.css, .nojekyll, termos/, privacidade/) para a raiz do repositório.
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, pasta `/ (root)`.
4. Endereços: https://<usuario>.github.io/taligadomano-cortes/ , .../termos/ , .../privacidade/
5. No portal do TikTok, em cada URL "not verified": Verify → URL prefix → baixe o arquivo `tiktok….txt` e envie
   para a raiz do repositório (ao lado do index.html). Espere ~1 min e clique em Verify.
